#  Sales & Inventory Data Analysis — SQL Project

##  Project Overview

This project focuses on analyzing a **Sales & Inventory Management System** using SQL. The database contains information on **customers, suppliers, products, orders, order details, and payments**, allowing transactional data to be transformed into meaningful business insights.

The analysis explores **sales performance, customer purchasing behavior, product performance, revenue generation, inventory movement, and supplier performance** to support data-driven business decisions.

---

##  Tools & Technologies

* **MySQL** — Database creation and SQL analysis
* **SQL** — Data querying and business analysis
* **Relational Database Design** — Primary and foreign-key relationships
* **GitHub** — Project documentation and portfolio presentation

---

##  Business Questions

The project answers key business questions, including:

* Which customers have placed orders?
* How many orders has each customer made?
* What products are supplied by each supplier?
* What are the daily sales totals?
* What is the total revenue generated?
* Which are the top 5 best-selling products?
* Which customers spend above a specified amount?
* What is the average order value?
* Which products have never been sold?
* Which customers have never placed an order?
* Which orders contain more than three products?
* Who are the most loyal customers?
* Which products are slow-moving?
* Which products should be prioritized for restocking?
* Which supplier generates the highest revenue?

## These questions are implemented through the SQL queries in the project.
